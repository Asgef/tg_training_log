## 💡 СОВЕТЫ ПО ВЫПОЛНЕНИЮ

### Для критических задач (P0)
1. **Не спешите** - эти изменения затрагивают всю кодовую базу
2. **Тестируйте каждый шаг** - даже без автотестов, ручное тестирование обязательно
3. **Делайте маленькие коммиты** - легче откатить если что-то пойдёт не так
4. **Code review** - критические изменения должны проверяться

### Для высокого приоритета (P1)
1. **Добавляйте метрики сразу** - чтобы видеть результат улучшений
2. **Документируйте решения** - ADR для ключевых решений
3. **Тестируйте в production-like окружении** - используйте Docker Compose

### Для среднего приоритета (P2)
1. **Рефакторьте постепенно** - не переписывайте всё сразу
2. **Поддерживайте обратную совместимость** - особенно для API
3. **Пишите тесты перед рефакторингом** - чтобы не сломать функциональность

### Общие советы
- **Один PR = одна задача** (или логически связанная группа)
- **Пишите осмысленные commit messages**
- **Обновляйте документацию вместе с кодом**
- **Празднуйте маленькие победы** 🎉

## 🔄 ПРОЦЕСС РАБОТЫ С ЗАДАЧАМИ

1. **Выберите задачу** из текущего спринта
2. **Создайте ветку** `feature/TASK-XXX-short-description`
3. **Реализуйте** с учётом требований из PROJECT_ANALYSIS.md
4. **Напишите тесты** (для P2+ задач)
5. **Обновите документацию** если нужно
6. **Создайте PR** с описанием изменений
7. **Code review** (если есть команда)
8. **Merge** в main
9. **Отметьте задачу** как выполненную
10. **Деплой** (если это production-ready изменение)

## ✅ DEFINITION OF DONE

Задача считается выполненной когда:

### Для всех задач
- [ ] Код написан и работает
- [ ] Нет предупреждений ruff/mypy
- [ ] Код прошёл self-review
- [ ] Нет TODO/FIXME комментариев (или они задокументированы как отдельные задачи)

### Для P0-P1 задач
- [ ] Ручное тестирование проведено
- [ ] Логирование добавлено для ключевых операций
- [ ] Обработка ошибок на месте
- [ ] Документация обновлена (если нужно)

### Для P2-P3 задач
- [ ] Unit тесты написаны
- [ ] Test coverage > 80% для изменённого кода
- [ ] Integration тесты (если применимо)
- [ ] Документация в коде (docstrings)

### Для P3 задач с новыми фичами
- [ ] E2E тесты написаны
- [ ] Пользовательская документация обновлена
- [ ] Changelog обновлён
