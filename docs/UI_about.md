## ТЗ: Раздел «ℹ️ Справка / About» в Telegram-боте (UI + тексты)

### 1) Цель

Реализовать раздел «ℹ️ Справка», который:

* кратко объясняет назначение бота и основной сценарий использования;
* даёт доступ к тематическим разделам справки;
* содержит готовые кнопки для перехода к ключевым действиям (добавить тренажёр, начать тренировку, подключить таблицу, выгрузить данные).

---

## 2) Точка входа

### 2.1 Кнопка в главном меню

Добавить в главное меню кнопку:

* **ℹ️ Справка**

По нажатию бот отправляет сообщение **“Справка (главная)”** (см. 3.1) с inline-кнопками навигации.

---

## 3) Сообщения справки (тексты строго как ниже)

> Все сообщения справки должны отображаться как **одно сообщение**, которое обновляется при навигации (редактированием текста и кнопок).
> Исключение: если Telegram не позволяет редактировать (например, истекло время) — допускается отправка нового сообщения.

### 3.1 Сообщение: «Справка (главная)»

**Текст:**

```
ℹ️ Справка

Этот бот помогает вести журнал тренировок:
• тренировки → тренажёры → подходы
• у тренажёров есть мышечные зоны и мышцы
• данные можно выгружать в Google Таблицу для графиков и анализа

Выбери раздел ниже.
```

**Кнопки (inline, 2 ряда):**
Ряд 1:

* 🚀 Быстрый старт
* 💪 Тренажёры

Ряд 2:

* 🧾 Подходы и тренировки
* 📊 Google Таблица

Ряд 3:

* 🧠 Термины (RIR)

## 4) Требования к навигации

* Переход между разделами справки выполняется нажатием inline-кнопок.
* В каждом разделе должна быть кнопка **⬅️ Назад в справку**, возвращающая к сообщению “Справка (главная)”.
* Кнопки действий (например, “▶️ Начать тренировку”) должны переводить пользователя в соответствующий раздел/действие бота.

---

## 5) Требования к интеграции с текущими функциями

Кнопки в справке должны вызывать существующие пользовательские действия:

* **➕ Добавить тренажёр** → открывает экран выбора способа добавления (библиотека/вручную) либо сразу “Создать вручную” (по решению текущего UX).
* **📚 Добавить из библиотеки** → открывает экран библиотеки тренажёров.
* **➕ Создать вручную** → запускает сценарий ручного создания тренажёра.
* **🏋️ Мои тренажёры** → открывает список пользовательских тренажёров.
* **🏋️ Начать тренировку** → запускает тренировку (если уже активна — показать текущий статус).
* **➕ Записать подход** → открывает UI записи подхода (если тренировка не активна — показать сообщение, что нужно начать тренировку).
* **🔗 Подключить Google Таблицу** → запускает сценарий привязки таблицы.
* **📤 Выгрузить данные** → запускает выгрузку (если таблица не подключена — показать сообщение о необходимости подключения).

---

## 6) Критерии готовности (DoD)

Считается выполненным, если:

1. В главном меню есть кнопка **ℹ️ Справка**.
2. Справка открывается “главным” сообщением с навигацией по разделам.
3. Каждый раздел отображает текст строго по ТЗ и имеет кнопку **⬅️ Назад в справку**.
4. Все “кнопки действий” из справки ведут в соответствующие реальные функции бота.
