Вот техническое задание (ТЗ) на **UI управления тренировкой** в Telegram-боте. Только поведение интерфейса, без описания внутренней логики.

---

## 🧾 Техническое задание: UI управления тренировкой

### Сценарий 1: До начала тренировки

При открытии главного меню, если у пользователя нет активной тренировочной сессии:

* Отображается кнопка:

  ```
  [ ▶️ Начать тренировку ]
  ```

---

### Сценарий 2: Тренировка активна

После нажатия “Начать тренировку” и до её завершения или отмены:

* Кнопка “Начать тренировку” исчезает.
* Отображаются две новые кнопки:

  ```
  [ ⏹️ Завершить тренировку ]   [ ❌ Отменить тренировку ]
  ```

---

### Кнопка «Завершить тренировку»

* По нажатию завершается текущая активная тренировка.
* Кнопки “Завершить тренировку” и “Отменить тренировку” исчезают.
* Кнопка “Начать тренировку” снова становится доступной в главном меню.

---

### Кнопка «Отменить тренировку»

Поведение зависит от наличия подходов в текущей тренировке:

#### Если подходов нет:

* Тренировка отменяется немедленно, без подтверждения.
* Кнопки “Завершить” и “Отменить” скрываются.
* Кнопка “Начать тренировку” снова появляется.

#### Если подходы есть:

* Отображается предупреждение:

  > ⚠️ У тебя уже есть подходы в этой тренировке.
  > Если ты отменишь тренировку, **все они будут удалены**.
  >
  > ❗ Продолжить?

* Кнопки подтверждения:

  ```
  [ ✅ Да, удалить всё ]   [ ❌ Отмена ]
  ```

* При подтверждении тренировка и все связанные с ней подходы удаляются.

* Интерфейс возвращается к состоянию “До начала тренировки”.

---

Если потребуется — готов оформить все UI-состояния меню в виде макета или диаграммы.
