

### Экран: «Добавить из библиотеки»

Бот присылает одно сообщение:

**➕ Добавить тренажёр из библиотеки**
Выберите действие:

Кнопки (inline):

* `🔍 Поиск`
* `📋 Показать список`
* `↩️ Назад`

### `📋 Показать список`

Показывается **страница** из N тренажёров кнопками (например 8–10 штук), плюс навигация:

* 8–10 кнопок с названиями
* `⬅️ Назад` `➡️ Вперёд`
* `🔍 Поиск` `↩️ Назад`

Нажал тренажёр → бот показывает карточку тренажёра:

**Жим лёжа (штанга)**
Зоны: …
Мышцы: …

Кнопки:

* `✅ Добавить себе`
* `↩️ К списку`

### `🔍 Поиск`

Бот пишет: **«Введите часть названия»**
И сразу рядом даёт кнопку:

* `❌ Отмена`

Пользователь вводит текст → бот показывает результаты списком кнопок + пагинация. Ноль результатов → “Ничего не найдено” + кнопка “показать список”.

Это полностью убирает проблему “пустого сообщения”.
